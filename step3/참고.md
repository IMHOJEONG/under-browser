import tkinter와 import tkinter.font을 각각 해야 하는 이유는 다음과 같습니다:

import tkinter는 tkinter 모듈 전체를 불러옵니다.
하지만, tkinter.font는 tkinter의 하위 모듈(서브패키지)이기 때문에
import tkinter만으로는 tkinter.font.Font를 바로 사용할 수 없습니다.

import tkinter.font을 추가하면
tkinter.font 내부의 클래스(Font)와 함수들을 사용할 수 있게 됩니다.

즉,

import tkinter만 하면 tkinter.Tk(), tkinter.Canvas() 등은 쓸 수 있지만
tkinter.font.Font를 쓰려면 반드시 import tkinter.font도 해줘야
tkinter.font 네임스페이스가 활성화되어 에러 없이 사용할 수 있습니다.
파이썬의 하위 모듈(서브패키지)은 별도로 import해야 접근이 가능합니다.
그래서 두 줄 모두 필요합니다!
