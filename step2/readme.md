## 화면 그리기 

- 대부분의 프로그램은 그래픽 툴킷을 사용해, 이 과정을 간소화 

- python의 tkinter 

- tk의 좌표계: x축(왼쪽에서 오른쪽으로), y축(위에서 아래로) 커짐

- 예시를 분석해볼 것: https://tkdocs.com/tutorial/firstexample.html

### 모바일 

- visual viewport(시각적 뷰포트)

- 핀치 줌 

- 화면 픽셀 밀도는 훨씬 더 높지만, 전체 화면 해상도는 일반적으로 더 낮음 

### 스크롤 - 웹 페이지에서 가장 빈번하게 이루어지는 상호작용 

- 브라우저와 같은 그래픽 애플리케이션은 보통 화면의 갱신 속도 (frame rate)를 정확히 60Hz 이내에 다시 그리는 것을 목표로 함 

    - 즉, 브라우저가 모든 작업을 60분의 1초 (16밀리초) 이내에 완료해야 함 

    - 16ms = 애플리케이션의 animation frame budget
